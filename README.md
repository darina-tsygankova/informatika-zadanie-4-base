# Задание 4. База данных «Успеваемость по информатике»

**Выполнила: Цыганкова Дарина**

## Что сделано

Я спроектировала и реализовала базу данных для предметной области «Успеваемость по информатике» в формате LibreOffice Base.

Основной файл для проверки:

```text
uspevaemost_po_informatike_tsygankova_darina.odb
```

## Структура базы данных

В базе данных есть две таблицы.

### Таблица «Ученики»

| Поле | Тип | Назначение |
| --- | --- | --- |
| `ID_ученика` | INTEGER | Первичный ключ ученика. |
| `Фамилия` | VARCHAR(40) | Фамилия ученика. |
| `Имя` | VARCHAR(40) | Имя ученика. |
| `Класс` | VARCHAR(4) | Класс ученика, например `9А`. |
| `Дата_рождения` | DATE | Дата рождения ученика. |

### Таблица «Успеваемость»

| Поле | Тип | Назначение |
| --- | --- | --- |
| `ID_Оценки` | INTEGER | Первичный ключ записи об оценке. |
| `ID_ученика` | INTEGER | Внешний ключ на таблицу «Ученики». |
| `Четверть` | INTEGER | Номер четверти. |
| `Оценка` | INTEGER | Оценка по информатике. |

## Ключи и связь

Для таблицы «Ученики» первичным ключом является поле `ID_ученика`.

Для таблицы «Успеваемость» первичным ключом является поле `ID_Оценки`.

Между таблицами установлена связь:

```text
Успеваемость.ID_ученика -> Ученики.ID_ученика
```

Это связь «один ко многим»: у одного ученика может быть несколько записей об оценках.

## Записи в таблицах

В таблицу «Ученики» внесено 6 записей: ученики 7, 8 и 9 классов. В таблицу «Успеваемость» внесено 6 записей с оценками за разные четверти.

Данные подобраны так, чтобы можно было выполнить сортировку, фильтрацию и запрос из условия задания.

## Сохраненные запросы

В базе подготовлены запросы:

1. `01_Ученики_сортировка_класс_фамилия` — сортировка учеников по классу, затем по фамилии.
2. `02_Ученики_9_класс` — фильтр, который оставляет только учеников 9-х классов.
3. `03_Успеваемость_1_2_четверти` — фильтр успеваемости только за 1-ю и 2-ю четверти.
4. `04_Девятиклассники_1_четверть_5` — выборка всех девятиклассников, имеющих за 1 четверть оценку 5.

Последний запрос должен вернуть:

```text
Иванова Анна, 9А, 1 четверть, оценка 5
Петров Максим, 9Б, 1 четверть, оценка 5
```

## Как открыть

1. Распаковать архив.
2. Открыть файл `uspevaemost_po_informatike_tsygankova_darina.odb` в LibreOffice Base.
3. Открыть раздел «Таблицы», чтобы увидеть таблицы «Ученики» и «Успеваемость».
4. Открыть раздел «Запросы», чтобы проверить сортировки, фильтры и итоговый запрос.
